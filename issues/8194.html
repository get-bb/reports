1. TL;DR

Hidden agent-created browser pages retain disabled background throttling after the automation controller detaches. A focused regression exercises the real view manager and CDP adapter, with Electron replaced by the repository's existing boundary fake. Both fresh pages and pages recreated after eviction return false where background throttling should return true. The same two failures repeat in a second clean checkout of trusted main. This confirms the lifecycle defect, not the macOS CPU percentages or compositor measurements reported by the author.

5. Root cause

The new agent page path explicitly disables throttling; the cold page restoration path derives its initial setting from agent ownership. Both feed the WebContentsView factory.

The CDP attach path saves that initial setting before temporarily disabling throttling. The release path faithfully restores the saved setting, which is already false for agent-owned pages. Therefore ending the controller lifetime cannot restore ordinary hidden-page throttling. Ownership and active control are different lifetimes; ownership must not permanently request unthrottled rendering.

History: the fresh-page false default is attributed to commit fe3ca9385b6 by git blame. The server-inactive override is separate and already forces true; existing coverage is retained to ensure controller release cannot defeat that override. Actual Electron visibility/frame scheduling is outside this unit reproduction.

6. Proposed fix and validation

Initialize all native browser entries with background throttling enabled at the existing shared factory, removing the per-caller creation option. Keep the existing CDP/capture temporary overrides and release restoration unchanged. This covers new, restored, and user-created tabs without new public API, protocol, dependency, persisted data, packaging, or release changes.

The candidate changes only two desktop subsystem files: 60 additions plus 37 deletions = 97 changed text lines (production 1/5; tests 59/32). The previous restored-agent ownership test is extended, not removed: both table cases still check retention beyond the idle deadline.

  • Before fix, both cases fail at the intended post-detachment assertion in each trusted baseline checkout.
  • After fix, the owning view-manager file passes all 116 tests; seven relevant browser suites pass all 158 tests.
  • Desktop typecheck passes. Full build passes 74 tasks. Formatting and git diff --check pass.
  • The broader desktop suite reports 656 passed, 2 skipped, and one unrelated packaging test failure: Electron cannot load libglib-2.0.so.0. That same packaging failure reproduces on unchanged production code in checkout B. No attempt was made to change packaging or install dependencies.
  • Remaining release check: repeat hidden-window frame/CPU measurements and hidden-page input/screenshot operations on macOS. No signed bundle or release is claimed.
