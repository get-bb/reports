#7595 · Completed plugin invocations retain cancellation bookkeeping

BugHighEffort: Lowplugins · perf · confirmed-repro Issue · 2026-11-15 · base da3e60b81d560e114a2bec724bb59c997aaaae7f

Verdict: REPRODUCED · Root-cause confidence: high

1. TL;DR

A loaded plugin accumulates V8 cancellation bookkeeping when successful RPC invocations have caller signals. In a real plugin service with a migrated SQLite database, 256 completed invocations left 256 additional WeakCells after repeated garbage collection; 256 control invocations without caller signals left none. This reproduced twice, from separate clean checkouts of the same trusted main commit. The long-lived stopping signal is composed into a fresh AbortSignal.any on every signalled call, and completion never disposes that composition. This verifies the per-call retention mechanism, not the reporter's production heap size, hourly byte-growth estimate, or an actual server crash.

import { mkdtemp, rm, writeFile } from "node:fs/promises";
import { Session } from "node:inspector/promises";
import { tmpdir } from "node:os";
import { join } from "node:path";
import { setImmediate as nextTurn } from "node:timers/promises";
import { getHeapSnapshot } from "node:v8";
import { expect, it } from "vitest";
import { defineRpcContract } from "@get-bb/plugin-sdk";
import { z } from "zod";
import { createTestAppHarness } from "../../helpers/test-app.js";

const heapSchema = z.object({
  snapshot: z.object({ meta: z.object({ node_fields: z.array(z.string()) }) }),
  strings: z.array(z.string()),
  nodes: z.array(z.number()),
});

async function weakCellCount(): Promise<number> {
  const session = new Session();
  session.connect();
  try {
    for (let round = 0; round < 4; round += 1) {
      await session.post("HeapProfiler.collectGarbage");
      await nextTurn();
    }
  } finally {
    session.disconnect();
  }
  const chunks: Buffer[] = [];
  for await (const chunk of getHeapSnapshot()) chunks.push(Buffer.from(chunk));
  const heap = heapSchema.parse(JSON.parse(Buffer.concat(chunks).toString()));
  const nameOffset = heap.snapshot.meta.node_fields.indexOf("name");
  let count = 0;
  for (
    let offset = nameOffset;
    offset < heap.nodes.length;
    offset += heap.snapshot.meta.node_fields.length
  ) {
    if (heap.strings[heap.nodes[offset]!] === "system / WeakCell") count += 1;
  }
  return count;
}

it("releases cancellation bookkeeping after completed plugin RPC calls", async () => {
  const harness = await createTestAppHarness();
  const pluginDir = await mkdtemp(join(tmpdir(), "bb-rpc-retention-"));
  try {
    await writeFile(
      join(pluginDir, "package.json"),
      JSON.stringify({
        name: "bb-plugin-retention-probe",
        version: "0.1.0",
        bb: {
          name: "Retention probe",
          description: "RPC lifetime regression fixture",
          branding: { icon: "Zap" },
          server: "./server.ts",
        },
      }),
    );
    await writeFile(join(pluginDir, "server.ts"), "export default () => {};");
    expect((await harness.pluginService.installPath(pluginDir)).status).toBe(
      "running",
    );
    const api = harness.pluginService.getApi("retention-probe");
    if (api === undefined) throw new Error("probe plugin unavailable");
    let retainedSignal: AbortSignal | undefined;
    api.rpc.register(
      defineRpcContract({ probe: { input: z.null(), output: z.null() } }),
      {
        probe(_input, context) {
          retainedSignal = context.experimental_signal;
          return null;
        },
      },
    );
    const lookup = harness.pluginService.getRpcHandler(
      "retention-probe",
      "probe",
    );
    if (lookup.outcome !== "found")
      throw new Error("probe handler unavailable");
    async function invoke(signal: AbortSignal | null): Promise<void> {
      if (lookup.outcome !== "found")
        throw new Error("probe handler unavailable");
      expect(
        await harness.pluginService.invokeRpcHandler(
          lookup.owner,
          "probe",
          lookup.value,
          null,
          { kind: "client" },
          signal,
        ),
      ).toEqual({ ok: true, result: null });
    }
    for (let call = 0; call < 16; call += 1) await invoke(null);
    retainedSignal = undefined;
    const before = await weakCellCount();
    for (let call = 0; call < 256; call += 1) await invoke(null);
    retainedSignal = undefined;
    const withoutCaller = await weakCellCount();
    for (let call = 0; call < 256; call += 1) {
      await invoke(new AbortController().signal);
    }
    retainedSignal = undefined;
    const withCaller = await weakCellCount();
    const caller = new AbortController();
    await invoke(caller.signal);
    const completedSignal = retainedSignal;
    caller.abort("after-completion");
    console.log(
      JSON.stringify({
        before,
        withoutCaller,
        withCaller,
        controlDelta: withoutCaller - before,
        signalledDelta: withCaller - withoutCaller,
        stopped: lookup.owner.stopping.signal.aborted,
        completedSignalAborted: completedSignal?.aborted,
        completedSignalReason: completedSignal?.reason,
      }),
    );
    expect(withoutCaller - before).toBeLessThan(16);
    expect(withCaller - withoutCaller).toBeLessThan(16);
  } finally {
    await harness.pluginService.stop();
    await harness.cleanup();
    await rm(pluginDir, { recursive: true, force: true });
  }
}, 120_000);

5. Root cause

invokeRpcHandler passes the invocation signal to the actual registered plugin handler. invokeWrapped chooses the live instance stopping signal and composes it with each caller signal:

const lifetime = instance.stopping.signal.aborted
  ? released
  : instance.stopping.signal;
const signal =
  callerSignal === undefined
    ? lifetime
    : AbortSignal.any([callerSignal, lifetime]);

Execution settlement removes the invocation from the active set and updates statistics. The finally block removes only the separately installed release listener. Neither operation detaches the composite signal's bookkeeping.

The local Node runtime's built-in internal/abort_controller source explains the retained V8 cells: its AbortSignal.any registers each source in sourceSignalsCleanupRegistry, with no unregister token or per-call completion operation. The long-lived source remains a live finalization target even after the composite itself becomes unreachable. A shrinking dependent-signal set therefore does not imply that all finalization bookkeeping was reclaimed. This distinction is why measuring ordinary event listeners alone would miss the leak.

The direct test localizes retention to signalled calls: the same service, schemas, handler, and invocation path show zero control growth. It does not establish that every WeakCell elsewhere in a production heap has this cause.

6. Proposed fix and automatic-fix safety

A disposable signal fan-in could forward caller and instance cancellation, preserve the first abort reason, handle already-aborted inputs, and release source listeners once execution settles. It must keep cancellation active while the handler is still executing, including during reload drain and caller release.

No automatic fix PR: completion-scoped disposal changes observable behavior for handlers retaining the supplied signal. The test demonstrates that an abort after a successful return currently reaches that signal with reason after-completion. The public experimental signal contract describes caller and reload cancellation but does not explicitly limit the signal to an active invocation. Choosing whether this late behavior should remain supported is a signal-lifetime contract decision. The autopilot's no-product-or-architecture-decision condition is therefore not satisfied. No production patch, fix commit, or branch was pushed.

Next step: decide and document that lifetime, then test caller abort, plugin stop, already-aborted input, success/rejection cleanup, first-reason preservation, late abort, repeated-call heap retention, and reload drain before replacing the composition. The existing lifecycle tests cover several active-call cancellation cases but not the measured heap retention.
