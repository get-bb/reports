#6312 · Desktop broker discovery across filesystem boundaries

1. TL;DR

The desktop broker client cannot register a window when its local filesystem has no broker descriptor, even when the host daemon's broker is reachable. A real daemon broker and the production desktop client reproduce this with separate temporary directories on Linux. Copying the private descriptor into a searched desktop directory makes the existing client register on its next retry, without restarting it. The reported native Windows/WSL2 arrangement, mirrored networking, Electron UI, CDP, and page screenshots were not available here, so the complete platform report is only partially reproduced. Main also searches other local machine directories, not just the two initial locations described by the reporter; all those candidates still require a desktop-local descriptor.

Complete reproduction script

The test is embedded here so reproduction does not depend on a separately published executable artifact. It extends coverage beyond existing tests by exercising an actually reachable production daemon with no desktop-local descriptor; it adds no production export or hook.

import assert from "node:assert/strict";
import { once } from "node:events";
import { chmod, copyFile, mkdir, mkdtemp, rm } from "node:fs/promises";
import { tmpdir } from "node:os";
import { join } from "node:path";
import { setTimeout as delay } from "node:timers/promises";
import { WebSocket } from "ws";
import { startDesktopBrowserBroker } from "../../host-daemon/src/desktop-browser-broker.ts";
import { createDesktopBrowserBrokerClient } from "../src/desktop-browser-broker-client.ts";

const root = await mkdtemp(join(tmpdir(), "bb-6312-probe-"));
const serverUrl = "https://desktop-repro.invalid";
const desktopHome = join(root, "desktop-home");
const daemonData = join(root, "daemon-data");
const instance = {
  instanceId: "instance_repro",
  generation: "generation_repro",
  label: "Isolated probe window",
};
let hostId = null;
let proofRequests = 0;
let client;
let directSocket;
const daemon = await startDesktopBrowserBroker({
  dataDir: daemonData,
  hostId: "host_repro",
  serverUrl,
  onChanged: () => undefined,
});
daemon.setConnected(true);

try {
  directSocket = new WebSocket(daemon.descriptor.url, {
    headers: { authorization: `Bearer ${daemon.descriptor.token}` },
  });
  await once(directSocket, "open");
  console.log("Authenticated loopback WebSocket reachable: true");
  const closed = once(directSocket, "close");
  directSocket.close();
  await closed;

  client = createDesktopBrowserBrokerClient({
    dataDir: join(desktopHome, ".bb"),
    homeDir: desktopHome,
    getServerUrl: () => serverUrl,
    broker: {
      setHostId: (value) => { hostId = value; },
      setServerOrigin: () => undefined,
      listInstances: () => [instance],
      subscribeInstances: () => () => undefined,
      subscribe: () => () => undefined,
    },
    fetchImpl: async (_input, init) => {
      proofRequests += 1;
      const request = JSON.parse(init.body);
      return Response.json(daemon.prove(request.challenge));
    },
  });
  await delay(2500);
  const absent = await daemon.request({ type: "desktop.browser.list_instances" });
  console.log("Separated filesystem result:", JSON.stringify(absent));
  console.log("Proof requests without a desktop-local descriptor:", proofRequests);
  assert.deepEqual(absent, { instances: [] });
  assert.equal(hostId, null);
  assert.equal(proofRequests, 0);
  if (process.argv.includes("--expect-registration")) {
    assert.deepEqual(absent, { instances: [instance] },
      "A reachable daemon in a separate filesystem should register the desktop window");
  }

  const localDirectory = join(desktopHome, ".bb-machines", "desktop-repro.invalid");
  await mkdir(localDirectory, { recursive: true, mode: 0o700 });
  const descriptorName = "desktop-browser-broker.json";
  const localDescriptor = join(localDirectory, descriptorName);
  await copyFile(join(daemonData, descriptorName), localDescriptor);
  await chmod(localDescriptor, 0o600);
  const deadline = Date.now() + 7000;
  let recovered;
  do {
    recovered = await daemon.request({ type: "desktop.browser.list_instances" });
    if (recovered.instances.length === 1) break;
    await delay(25);
  } while (Date.now() < deadline);
  assert.deepEqual(recovered, { instances: [instance] });
  assert.equal(hostId, "host_repro");
  console.log("After private descriptor copy, without client restart:", JSON.stringify(recovered));
  console.log("PASS: isolated discovery failure and copy recovery reproduced");
} finally {
  client?.stop();
  directSocket?.terminate();
  await daemon.close();
  await rm(root, { recursive: true, force: true });
}

5. Root cause

The broker descriptor is a local capability bootstrap: it contains the loopback endpoint and its authentication key. The daemon writes it privately under its own data directory. The desktop main process supplies its own data directory and its own operating-system home directory to the client. When those filesystem namespaces differ, a network connection to the server does not supply that local capability.

  • Daemon: loopback endpoint and private descriptor. 
    const descriptorPath = join(
  options.dataDir,
  DESKTOP_BROWSER_BROKER_DESCRIPTOR_FILE,
);
await writeFile(temporaryPath, JSON.stringify(descriptor), {
  mode: 0o600,
  flag: "wx",
});
await rename(temporaryPath, descriptorPath);
  • Main process: desktop-local directories and selected origin.
  • Client discovery and proof: every candidate must first pass readBrokerDescriptor(dataDir). The HTTP challenge is generated only after that read. With no candidate file, no proof request occurs and no WebSocket is opened. 
    const descriptor = await readBrokerDescriptor(dataDir);
signal.throwIfAborted();
const challenge = randomBytes(32).toString("hex");
  • Client connection and retry: registration starts only after discovery succeeds; retries cannot manufacture a missing credential.
  • Daemon instance list flattens registered peers. No desktop registration therefore means an empty list.
  • Server proof operation routes a challenge to a known host, rather than returning a descriptor or its secret.

The deeper issue is a mismatch between the local-capability discovery design and a desktop/daemon pair sharing networking but not filesystem storage. The existing alias-proof path validates locally available capabilities; it is not remote descriptor discovery. The isolated results establish that mechanism, not the availability or behavior of native Windows filesystem integration.

6. Proposed fix and safety gate

First choose a supported cross-OS discovery design and its trust model. An authenticated network bootstrap would need explicit capability scoping, endpoint identity, credential handling, and daemon compatibility review. Filesystem-based WSL discovery would instead need a supported distro/user/data-directory mapping and Windows/WSL ownership and permission validation. Do not simply expose or broadly copy the bearer credential.

Next experiment: repeat the inline probe with a native Windows desktop, a WSL-hosted daemon, and a reviewed descriptor-discovery mechanism; then verify native tab listing, automation navigation/capture, restart credential rotation, and rejection of untrusted descriptors. The Linux reproduction cannot validate those security and platform properties.
