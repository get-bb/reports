1. TL;DR

The desktop search bar is drawn in a separate transparent view with very little space around it. Executing the trusted document generator confirms a 344×48 view, a 328×32 bar, and only 8px of margin, while its shadow uses an 8px downward offset and a 24px blur. This supports the proposed clipping mechanism and the risk of a bright halo when the system foreground is light. The same generated document and geometry were obtained from a second clean checkout. The reported visible rectangle was not rendered here: the host lacks shared libraries required by both Chrome and Electron, so this is not a confirmed desktop visual reproduction.

CSS blur is not a strict finite-radius effect. The offset-plus-blur calculation is a useful warning, not proof that any particular smaller blur fits every last shadow pixel inside a viewport.

5. Root cause

The document constants specify width 344, height 48, and inset 8. The generated styles make the document transparent, hide body overflow, and give the bar a system-foreground shadow with an 8px vertical offset and 24px blur. The manager's transparent view construction and bounds calculation use the same dimensions. The loading path sets a transparent background and loads this data document.

These inputs leave little room for the blur to decay before the view boundary. A foreground-derived color can also make the halo brighter rather than darker in a dark color scheme. The exact macOS colors, final composited rectangle, and native hit testing remain unverified, so the root cause is supported at the source/generator boundary rather than proven by a native capture.

6. Proposed fix from first principles

Keep the existing view footprint and either remove the shadow or use a compact, dark shadow validated with actual composited pixels in both appearances. Do not assume an offset-plus-blur inequality proves that all visible blur tails fit. Increasing the transparent view size may change input interception, so that alternative needs native hit-testing verification. No production change or new regression test was committed in this investigation.
