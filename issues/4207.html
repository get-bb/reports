1. TL;DR

The local context hint returns 200,000 for the plain Opus model found in repository tests and 1,000,000 for its explicit extended variant. This repeats in a second clean checkout. Pooling supplies a custom base URL, but this investigation did not establish how a live Claude Max account changes its actual context limit. The model catalog preserves SDK-discovered extended variants; it does not synthesize variants absent from discovery. No production fix is proposed as verified.

5. Root cause

plugins/provider-claude-code/src/sdk-extraction.ts:382-L395 returns the default constant for plain model IDs outside the large-context allowlist. plugins/provider-claude-code/src/delta-translation.ts:1291-L1296 installs that hint in the translation state. This explains the local hint, not the remote prompt rejection.

plugins/account-pool/src/server.ts:284-L304 contributes a custom endpoint and auth token, plus a tool-search setting. The external CLI first-party detection claim was not executed or established here.

plugins/provider-claude-code/src/model-list.ts:83-L112 takes resolved model IDs from SDK discovery; apps/server/src/services/threads/thread-execution-override.ts:52-L68 rejects IDs absent from the catalog.
