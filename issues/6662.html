#6662 · Package artifacts omit MIT licensing

BugPriority: MediumEffort: Lowdesktop · pluginsGitHub issue2026-10-30 · base a1bf55b6a04c7948ae5ae0dcfcbdec27d2b507a2

Verdict: REPRODUCED · Root-cause confidence: high · reproduction label: confirmed-repro

1. TL;DR

The repository declares MIT, but the two public package manifests do not declare a license. The actual published archives for the versions in trusted main, bb-app 0.48.1 and @get-bb/plugin-sdk 0.6.104, also contain neither a license field nor a package-root license notice. A direct artifact audit produced ten failed license checks, then produced exactly the same failures from a second clean checkout of the same main commit. Source packing independently produces the same omission; there is no package-local notice or build step that supplies it. No automatic fix PR is opened because altering published metadata and archive contents is a packaging change, explicitly excluded by this automation's simple-fix policy.

    import { execFileSync } from "node:child_process";
import { mkdtempSync, readFileSync, rmSync, writeFileSync } from "node:fs";
import { tmpdir } from "node:os";
import { join, resolve } from "node:path";

const checkout = resolve(process.argv[2]);
const inspectRegistry = process.argv.includes("--registry");
const scratch = mkdtempSync(join(tmpdir(), "license-audit-"));
let failures = 0;

function check(condition, message) {
  console.log(`${condition ? "PASS" : "FAIL"} ${message}`);
  if (!condition) failures += 1;
}

function inspectArchive(archive, label) {
  const manifest = JSON.parse(execFileSync("tar", ["-xOf", archive, "package/package.json"], { encoding: "utf8" }));
  const entries = execFileSync("tar", ["-tzf", archive], { encoding: "utf8" }).trim().split("\n");
  const notices = entries.filter((entry) => /^package\/licen[cs]e(?:\.[^/]*)?$/i.test(entry));
  check(manifest.license === "MIT", `${label}: manifest license=${JSON.stringify(manifest.license ?? null)} (expected "MIT")`);
  check(notices.length > 0, `${label}: root license files=${JSON.stringify(notices)} (expected MIT notice)`);
}

try {
  check(JSON.parse(readFileSync(join(checkout, "package.json"), "utf8")).license === "MIT", "repository declares MIT");
  for (const directory of ["packages/bb-app", "packages/plugin-sdk"]) {
    const packageRoot = join(checkout, directory);
    const manifest = JSON.parse(readFileSync(join(packageRoot, "package.json"), "utf8"));
    const packed = JSON.parse(execFileSync("npm", ["pack", "--ignore-scripts", "--json", "--pack-destination", scratch], { cwd: packageRoot, encoding: "utf8", stdio: ["ignore", "pipe", "pipe"] }));
    inspectArchive(join(scratch, packed[0].filename), `local ${manifest.name}@${manifest.version}`);
    if (!inspectRegistry) continue;
    const metadataUrl = `https://registry.npmjs.org/${encodeURIComponent(manifest.name)}/${encodeURIComponent(manifest.version)}`;
    const metadataResponse = await fetch(metadataUrl);
    if (!metadataResponse.ok) throw new Error(`Registry metadata HTTP ${metadataResponse.status}`);
    const metadata = await metadataResponse.json();
    if (metadata.name !== manifest.name || metadata.version !== manifest.version) throw new Error("Registry identity mismatch");
    check(metadata.license === "MIT", `registry ${manifest.name}@${manifest.version}: license=${JSON.stringify(metadata.license ?? null)} (expected "MIT")`);
    const archiveUrl = new URL(metadata.dist.tarball);
    if (archiveUrl.protocol !== "https:" || archiveUrl.hostname !== "registry.npmjs.org") throw new Error("Unexpected registry archive host");
    const archiveResponse = await fetch(archiveUrl);
    if (!archiveResponse.ok) throw new Error(`Registry archive HTTP ${archiveResponse.status}`);
    const archive = join(scratch, "registry.tgz");
    writeFileSync(archive, Buffer.from(await archiveResponse.arrayBuffer()));
    inspectArchive(archive, `published ${manifest.name}@${manifest.version}`);
  }
  console.log(`RESULT ${failures} failed license checks`);
  process.exitCode = failures > 0 ? 1 : 0;
} finally {
  rmSync(scratch, { recursive: true, force: true });
}

5. Root cause

The monorepo root has "license": "MIT" and a LICENSE file, but npm publication occurs from each package directory rather than the repository root. Neither package manifest declares a license, neither package directory has a LICENSE, and their build/prepack paths do not copy the repository notice into those package roots. npm's archive selection therefore has no package-local notice to include. A files allowlist does not itself provide a file from outside the package directory. This is a distribution-metadata omission, not a change of the repository's license.

  • Root package manifest declares MIT; root notice supplies its terms.
  • bb-app manifest identity has no license field; publication files and prepack select built outputs and prune CLI chunks, not licensing.
  • SDK manifest identity and publication files omit licensing; runtime build assembles runtime entry files, not a package-root notice.
  • Application publication runs in the application package directory; SDK publication runs in the SDK package directory.

6. Proposed fix

In a separately authorized packaging change, declare MIT in each public package manifest and place the exact repository LICENSE notice in each package root before publication. Extend artifact-level coverage to inspect the packed manifest and notice bytes for both packages, including the normal prepack paths; keep any copied notices synchronized with the repository source. Rebuild and audit the resulting archives before publishing new versions. No source fix, branch, commit, or PR was attempted here because packaging/release changes fail the autopilot's simple-fix gate regardless of line count.
