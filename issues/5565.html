#5565 · Dynamic instruction clipping lacks diagnostics

BugPriority: LowEffort: Lowplugins GitHub issue2026-10-15 · base 411eac54ac16d0a3cb57d1de8396d37564884a73

Verdict: REPRODUCED · Root-cause confidence: high · reproduction label: confirmed-repro

1. TL;DR

Plugins can return dynamic guidance when BB resolves an agent configuration. At the trusted main commit, a 5,000-character nonblank result becomes 4,096 characters without any warning. The normalizer performs the slice and returns an ordinary successful result; neither the server caller nor the test harness diagnoses that transformation. The existing SDK documentation explicitly promises truncation, so the minimal compatible repair is to retain that behavior and add a plugin-scoped warning containing the original length and limit.

import { expect, it } from "vitest";
import type { PluginAgentConfigurationContext } from "../../backend-contract.js";
import { createFakePluginHost, makePluginAgentConfigurationContext } from "../index.js";

const configurationContext = makePluginAgentConfigurationContext();

it("resolves conditional tools, skills, context, and capped instructions without rebuilding registrations", async () => {
  const { bb, harness } = createFakePluginHost({
    pluginId: "conditional",
    agentSkillIds: ["alpha-skill", "beta-skill"],
  });
  for (const name of ["alpha_tool", "beta_tool"]) {
    bb.agents.registerTool({
      name,
      description: name,
      parameters: { type: "object" },
      execute: () => name,
    });
  }
  const contexts: PluginAgentConfigurationContext[] = [];
  bb.agents.configure((context) => {
    contexts.push(context);
    const alpha = context.host.id === "host-test";
    return {
      tools: [alpha ? "alpha_tool" : "beta_tool"],
      skills: [alpha ? "alpha-skill" : "beta-skill"],
      instructions:
        `${context.provider.id}:${context.provider.model}:`.padEnd(5000, "x"),
    };
  });

  const alpha = await harness.resolveAgentConfiguration(configurationContext);
  const betaContext = makePluginAgentConfigurationContext({
    thread: { id: "thread-beta" },
    host: { id: "host-beta", name: "Beta host" },
    provider: {
      id: "claude-code",
      model: "claude-opus",
    },
  });
  const beta = await harness.resolveAgentConfiguration(betaContext);

  expect(alpha.tools.map((tool) => tool.name)).toEqual(["alpha_tool"]);
  expect(alpha.skills).toEqual(["alpha-skill"]);
  expect(alpha.instructions).toHaveLength(4096);
  expect(harness.logEntries).toEqual([
    {
      level: "warn",
      message: expect.stringContaining(
        "configure() output.instructions truncated from 5000 to 4096 characters",
      ),
    },
    {
      level: "warn",
      message: expect.stringContaining(
        "configure() output.instructions truncated from 5000 to 4096 characters",
      ),
    },
  ]);
  expect(beta.tools.map((tool) => tool.name)).toEqual(["beta_tool"]);
  expect(beta.skills).toEqual(["beta-skill"]);
  expect(contexts).toEqual([configurationContext, betaContext]);
  expect(harness.registrations.agentTools.map((tool) => tool.name)).toEqual([
    "alpha_tool",
    "beta_tool",
  ]);
});

5. Root cause

Dynamic normalization validates the value's type, then slices nonblank text without returning or emitting any overflow signal:

const instructions =
  typeof output.instructions === "string" &&
  output.instructions.trim().length > 0
    ? output.instructions.slice(0, PLUGIN_AGENT_DYNAMIC_INSTRUCTIONS_MAX_CHARS)
    : null;

The server's successful-resolution path takes this normalized value and appends it to the dynamic instructions array. Its error wrapper only diagnoses thrown failures, not successful truncation. The supported testing host calls the same normalizer, returning the shortened instructions and logging only caught errors. This explains why ordinary plugin tests can pass while trailing guidance disappears.

The distinction is not an undocumented size limit: the SDK declaration explicitly promises truncation. In contrast, static tool instructions are rejected. The defect is the missing diagnostic for the documented lossy dynamic path.

6. Proposed fix and verified local repair

Add a required internal warning callback to the shared normalizer and call it only when meaningful instruction text is actually shortened. Route it through the real plugin logger on the server and the captured warning log in the testing host. Keep tool/skill selection, the 4,096-character cap, blank-text normalization, status, and public interfaces unchanged. The existing plugin logger already prefixes the plugin identity and writes both server output and the plugin log readable through existing plugin-log surfaces. Do not include the guidance text itself in diagnostics.

The local candidate passes the focused regression, all 373 SDK tests, and 34 tests in the server's agent-tool and plugin-SDK suites. SDK and server Turbo typechecks pass. Additional negative controls confirm no warning for exactly 4,096 characters or blank guidance. The tested candidate changes five files and 46 total added/deleted text lines, has no binary changes, and passes git diff --check. No dependencies, generated files, stored data, public protocols, or permissions change in that candidate.

Autopilot fix stopped: CI rejected the candidate because its SDK declaration change requires a version bump. More generally, the existing SDK publication contract also requires a new version for changed published runtime content. The registry confirms that SDK version 0.6.49 is already published. A complete shared-normalizer repair therefore needs the version constant and package manifest updated together. Even dropping the documentation edit leaves four necessary implementation/test files plus two version files: at least six files, exceeding this rule's five-file maximum. No version guard was bypassed and no additional fix changes were pushed after this constraint was discovered. Candidate PR #5568 was closed without merging, and its remote branch was removed. The tested approach remains useful for a separately authorized repair outside this narrow autopilot limit.
