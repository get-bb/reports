#4873 · Native image results retain non-image timeline items

BugLow priorityMedium effortproviders · provider-claude-code · provider-pi GitHub issue · October 4, 2026 · base 72279d019a9ac82351dd3f7bd70862cbd050a02e

PARTIALLY REPRODUCED · Root-cause confidence: high · Reproduction label: partial-repro

1. TL;DR

Two fresh trusted-main checkouts reproduce a concrete classification gap: successful native reads containing image blocks finish as ordinary file/tool items, not image-view items. Claude Code preserves its file-read shape and presentation; Pi preserves a generic read tool call and converts the image content to the text “[image]”. The existing app selects the image preview body by image-view kind, so these outputs do not select that body. This investigation tests translator-to-assembler behavior, not a live model session or browser: the complete visible symptom and host-file route remain unverified. No screenshot is claimed.

Why this affects preview selection

The detail renderer routes image-view to ImageWorkRowBody; file-read returns null. The image body resolves the host path and provides its image-opening button. The confirmed classification mismatch prevents selection of that image-specific body. Browser behavior, image decoding, and remote file availability are separate, untested boundaries.

Codex's native imageView branch shows the existing vocabulary that both providers can target without creating a new UI kind.

6. Proposed fix and autopilot gate

At each provider's completion boundary, validate native result blocks, confirm successful completion and a known native-read path, and promote to imageView with the existing image presentation. Never infer success from an extension alone. Preserve identity, error status, text-read behavior, and unrelated image-returning tools. Add coverage for missing paths, malformed result blocks, mixed text/image content, and overlapping tool IDs in different threads.

No automatic fix PR: completing this issue requires changes to two independently packaged provider implementations (Claude Code and Pi), exceeding this rule's one-existing-subsystem simple-fix gate. No production patch, branch, or push was attempted. The live preview claim is also unverified. The two failing regression artifacts are preserved for a broader authorized fix.
