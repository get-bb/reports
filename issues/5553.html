#5553 · Watcher shutdown and plain-root scope

BugHighEffort: Mediumhost · perf · partial-reproGitHub issue

October 15, 2026 · Trusted main commit 05771e3c82404328854468f0fff7f0f8203e2076

Verdict: PARTIALLY REPRODUCED · Root-cause confidence: medium overall; high for the two bounded findings below.

1. TL;DR

A real native watcher remains alive after its IPC connection is closed if completion of its unsubscribe operation is deliberately withheld. The child waits for cleanup before exiting and has no shutdown deadline. A separate native-filesystem experiment confirms that a plain project root reports changes inside output ignored by a nested repository, whereas an explicit ignore at an outer Git root excludes that output. Neither experiment recreates the reported daemon heap exhaustion or establishes that recycling leaks parent memory; recycling already sends SIGKILL on this trusted base. These are partial findings, not a reproduction of the full incident.

  1. Install and build the recorded trusted commit. Both full builds succeeded (66 tasks).
  2. Run disconnect.mjs. It bundles the trusted child entry with existing esbuild, forks it, waits for ready and subscribed, then disconnects IPC. The healthy control uses the unchanged real backend. The stalled variant opens a real native subscription, but deliberately replaces unsubscribe completion with an unresolved promise. Expected safety invariant: the child eventually terminates despite stalled cleanup. Actual: it is still alive at the 2-second observation deadline. The harness SIGKILLs it and awaits exit in finally, so no orphan is left behind. Exit 1 is the intended failing safety assertion, not a build failure.
  3. Run scope.mjs through the installed tsx loader. It writes to a nested repository's ignored output, first under a plain root and then under an outer Git root that explicitly ignores the nested tree. Exit 0 confirms both observed behaviors. The one-second event observation window is a bounded experiment, not a stress or performance measurement.

disconnect.mjs

import assert from "node:assert/strict";
import { fork } from "node:child_process";
import { once } from "node:events";
import fs from "node:fs/promises";
import { createRequire } from "node:module";
import os from "node:os";
import path from "node:path";

const checkout = path.resolve(process.argv[2] ?? ".");
const requireFromCheckout = createRequire(path.join(checkout, "package.json"));
const { build } = requireFromCheckout("esbuild");
const packageDir = path.join(checkout, "packages/host-watcher");
const bundleDir = await fs.mkdtemp(path.join(packageDir, "test/issue-5553-"));
const watchDir = await fs.mkdtemp(path.join(os.tmpdir(), "watch-disconnect-"));
const deadlineMs = 2000;

function receive(child, kind) {
  return new Promise((resolve, reject) => {
    const deadline = setTimeout(() => {
      child.off("message", onMessage);
      reject(new Error(`Timed out waiting for ${kind}`));
    }, 10000);
    function onMessage(message) {
      if (message.kind === kind) {
        clearTimeout(deadline);
        child.off("message", onMessage);
        resolve(message);
      }
    }
    child.on("message", onMessage);
  });
}

async function run(stalled) {
  const output = path.join(bundleDir, stalled ? "stalled.mjs" : "healthy.mjs");
  await build({
    entryPoints: [path.join(packageDir, "src/parcel-subprocess/parcel-child-entry.ts")],
    outfile: output,
    bundle: true,
    platform: "node",
    format: "esm",
    packages: "external",
    plugins: stalled ? [{
      name: "stall-native-unsubscribe",
      setup(builder) {
        builder.onResolve({ filter: /real-parcel-watcher\.js$/ }, () => ({
          path: "fault-backend",
          namespace: "fault",
        }));
        builder.onLoad({ filter: /.*/, namespace: "fault" }, () => ({
          resolveDir: path.join(packageDir, "src"),
          contents: `
            import native from "@parcel/watcher";
            export const realParcelWatcher = {
              async subscribe(...args) {
                await native.subscribe(...args);
                return {
                  unsubscribe() {
                    process.stderr.write("native cleanup entered; completion withheld\\n");
                    return new Promise(() => {});
                  }
                };
              }
            };
          `,
        }));
      },
    }] : [],
  });
  const child = fork(output, [], { execArgv: [], stdio: ["ignore", "ignore", "pipe", "ipc"] });
  let stderr = "";
  child.stderr.on("data", (data) => { stderr += data; });
  const exit = once(child, "exit");
  let deadline;
  try {
    await receive(child, "ready");
    const subscribed = receive(child, "subscribed");
    child.send({ kind: "subscribe", id: "probe", dir: watchDir });
    await subscribed;
    child.disconnect();
    const outcome = await Promise.race([
      exit.then(([code, signal]) => ({ exited: true, code, signal })),
      new Promise((resolve) => { deadline = setTimeout(() => resolve({ exited: false }), deadlineMs); }),
    ]);
    console.log(`${stalled ? "stalled" : "healthy"}: ${JSON.stringify(outcome)}`);
    if (stderr.trim()) console.log(stderr.trim());
    return outcome;
  } finally {
    clearTimeout(deadline);
    if (child.exitCode === null && child.signalCode === null) {
      child.kill("SIGKILL");
    }
    await exit;
  }
}

try {
  const healthy = await run(false);
  assert.equal(healthy.exited, true, "healthy native watcher must exit after IPC disconnect");
  const stalled = await run(true);
  assert.equal(stalled.exited, true, "watcher must exit after IPC disconnect even when unsubscribe stalls");
} finally {
  await fs.rm(bundleDir, { recursive: true, force: true });
  await fs.rm(watchDir, { recursive: true, force: true });
}

scope.mjs

import assert from "node:assert/strict";
import { execFileSync } from "node:child_process";
import fs from "node:fs/promises";
import os from "node:os";
import path from "node:path";
import { pathToFileURL } from "node:url";

const checkout = path.resolve(process.argv[2] ?? ".");
const { watchWorkspaceStatus } = await import(pathToFileURL(path.join(checkout, "packages/host-watcher/src/watch-status.ts")));
const root = await fs.mkdtemp(path.join(os.tmpdir(), "watch-scope-"));
const nested = path.join(root, "nested");
const output = path.join(nested, "build-output");

async function measure() {
  const changedPaths = new Set();
  let ready;
  let reject;
  const started = new Promise((resolve, fail) => { ready = resolve; reject = fail; });
  const stop = watchWorkspaceStatus(root, {
    onChange(event) { for (const changedPath of event.changedPaths) changedPaths.add(changedPath); },
    onReady: ready,
    onWatchError: reject,
  });
  let timeout;
  try {
    await Promise.race([started, new Promise((_, fail) => {
      timeout = setTimeout(() => fail(new Error("watch setup timed out")), 10000);
    })]);
    await fs.writeFile(path.join(output, "part-0/artifact.txt"), `${Date.now()}\n`);
    await new Promise((resolve) => setTimeout(resolve, 1000));
    return changedPaths.has(path.join(output, "part-0/artifact.txt"));
  } finally {
    clearTimeout(timeout);
    await stop();
  }
}

try {
  await fs.mkdir(output, { recursive: true });
  execFileSync("git", ["init", "-q", nested]);
  await fs.writeFile(path.join(nested, ".gitignore"), "/build-output/\n");
  for (let index = 0; index < 200; index += 1) {
    const directory = path.join(output, `part-${index}`);
    await fs.mkdir(directory);
    await fs.writeFile(path.join(directory, "artifact.txt"), "sample\n");
  }
  const plainRootReportsNestedIgnoredOutput = await measure();
  execFileSync("git", ["init", "-q", root]);
  await fs.writeFile(path.join(root, ".gitignore"), "/nested/\n");
  const gitRootReportsOuterIgnoredOutput = await measure();
  console.log(JSON.stringify({ directoriesInNestedIgnoredOutput: 200, plainRootReportsNestedIgnoredOutput, gitRootReportsOuterIgnoredOutput }));
  assert.equal(plainRootReportsNestedIgnoredOutput, true, "plain root reports output ignored by the nested repository");
  assert.equal(gitRootReportsOuterIgnoredOutput, false, "outer git ignore prunes the nested tree");
} finally {
  await fs.rm(root, { recursive: true, force: true });
}

5. Root Cause

Shutdown: the disconnect listener calls handler.dispose().finally(() => process.exit(0)). dispose awaits Promise.all of active subscription unsubscribes. With a native subscription still holding an event-loop handle, a never-settling unsubscribe prevents the explicit exit. There is no independent deadline in that path. The controlled fault proves this lifecycle vulnerability, not the natural occurrence of the native fault.

process.on("disconnect", () => {
  void handler.dispose().finally(() => process.exit(0));
});

Scope: the built-in ignored globs do not include arbitrary nested output. plain and Git ignore assembly adds Git-discovered ignores only for a Git root. workspace startup selects the plain path when the workspace itself lacks .git. It does not recursively discover each nested repository's ignore policy. The scope experiment observes the consequence with the native backend.

Important counterevidence: unsubscribe before subscription readiness acknowledges cancelled pending IDs immediately. the unsubscribe timeout calls killAndRespawn, and the real channel kill already sends SIGKILL. It would be incorrect to claim that adding a missing SIGKILL explains or fixes this incident on main.

Unresolved deeper cause: allocation retention in the daemon, natural native unsubscribe stalls, and the claimed relation between recycling and heap exhaustion require a representative workload and heap/process telemetry. IPC event batches are a candidate to measure, not an established leak.

6. Proposed Fix and PR Decision

Bound child shutdown after IPC disconnect independently of async cleanup, while retaining fast graceful cleanup. Validate a separate targeted patch against both healthy and deliberately stalled unsubscribe, including the case where unsubscribe was already in flight. That is a narrower lifecycle hardening change, not a demonstrated daemon-OOM fix.

Before changing plain-root traversal, specify which nested files the product must observe. Automatically pruning nested repositories or adding ignore configuration changes coverage and requires a product decision. Collect a parent heap profile and a native-hang reproduction before choosing memory/back-pressure changes.

No fix branch or PR was created: the reported OOM/recycling failure was not reproduced on trusted main. Only scope behavior and a fault-injected shutdown gap were established, so a verified root-cause OOM fix cannot satisfy the simple-fix gate. No open PR linked to this issue was found in the issue timeline or repository search during this run.
