#7698 · Local Git events redundantly resolve default-branch refs

Bug Priority: Low Effort: Low host perf confirmed-repro
Issue #7698 · 2026-11-17 · Base 1320c88e8abdd3f145bc9a5c305eace269fb2f28

Verdict: REPRODUCED · Root-cause confidence: high

1. TL;DR

The host daemon performs unnecessary Git subprocess work after local Git metadata changes, even when the default branch was already learned from a shared-ref snapshot. A real temporary repository, with only HEAD detached and all refs unchanged, triggers one fresh default-branch resolution. Git tracing records four subprocesses for the event: the needed local status read plus three redundant default-branch subprocesses. This does not change the displayed default branch; it adds avoidable work per local-event batch. The same agent repeated the regression in a second clean checkout and obtained the same expected failure.

import { execFileSync } from "node:child_process";
import { mkdtemp, readFile, rm, writeFile } from "node:fs/promises";
import os from "node:os";
import path from "node:path";
import type { WatchWorkspaceArgs } from "@bb/host-watcher";
import { provisionWorkspace } from "@bb/host-workspace";
import { expect, it, vi } from "vitest";
import { WatchManager } from "./watch-manager.js";

it("reuses known default refs for a HEAD-only change without spawning ref readers", async () => {
  const root = await mkdtemp(path.join(os.tmpdir(), "bb-7698-git-"));
  const tracePath = path.join(root, "git-trace.jsonl");
  const previousTrace = process.env.GIT_TRACE2_EVENT;
  let watch: WatchWorkspaceArgs | undefined;
  let manager: WatchManager | undefined;
  const git = (...args: string[]) =>
    execFileSync("git", args, { cwd: root, encoding: "utf8" }).trim();
  try {
    git("init", "--quiet", "--initial-branch=main");
    await writeFile(path.join(root, "sample.txt"), "initial\n");
    git("add", "sample.txt");
    git(
      "-c",
      "user.name=Reproduction",
      "-c",
      "user.email=repro@invalid.test",
      "-c",
      "core.hooksPath=/dev/null",
      "-c",
      "commit.gpgSign=false",
      "commit",
      "--quiet",
      "-m",
      "initial",
    );
    const refsBefore = git(
      "for-each-ref",
      "--format=%(refname) %(objectname) %(symref)",
    );
    const workspace = await provisionWorkspace({ path: root });
    const getDefaultBranch = vi.spyOn(workspace, "getDefaultBranch");
    const onWorkspaceMetadataChanged = vi.fn();
    const onWorkspaceStatusWatchError = vi.fn();
    manager = new WatchManager({
      hostWatcher: {
        watchWorkspace(args) {
          watch = args;
          return () => undefined;
        },
        watchThreadStorage: () => () => undefined,
      },
      provisionWorkspace: async () => workspace,
      onWorkspaceMetadataChanged,
      onWorkspaceStatusWatchError,
    });
    await manager.replaceWatchSet({
      generation: 1,
      workspaceTargets: [
        {
          environmentId: "repro-7698",
          workspaceContext: { workspacePath: root },
          mergeBaseBranch: null,
        },
      ],
      threadStorageTargets: [],
    });
    expect(watch).toBeDefined();
    watch!.onReady?.();
    await vi.waitFor(() =>
      expect(onWorkspaceMetadataChanged).toHaveBeenCalledTimes(1),
    );
    expect(
      onWorkspaceMetadataChanged.mock.calls[0]?.[0].workspace,
    ).toMatchObject({
      branchName: "main",
      defaultBranch: "main",
    });
    getDefaultBranch.mockClear();
    git("checkout", "--quiet", "--detach", "HEAD");
    const refsAfter = git(
      "for-each-ref",
      "--format=%(refname) %(objectname) %(symref)",
    );
    expect(refsAfter).toBe(refsBefore);
    process.env.GIT_TRACE2_EVENT = tracePath;
    watch!.onChange({
      kind: "workspace-status-changed",
      environmentId: "repro-7698",
      changeKinds: ["workspace-git-changed"],
      changedPaths: [path.join(root, ".git", "HEAD")],
    });
    await vi.waitFor(() =>
      expect(onWorkspaceMetadataChanged).toHaveBeenCalledTimes(2),
    );
    expect(
      onWorkspaceMetadataChanged.mock.calls[1]?.[0].workspace,
    ).toMatchObject({
      branchName: null,
      defaultBranch: "main",
    });
    expect(onWorkspaceStatusWatchError).not.toHaveBeenCalled();
    const commands = (await readFile(tracePath, "utf8"))
      .trim()
      .split("\n")
      .map((line) => JSON.parse(line) as { event: string; argv?: string[] })
      .filter((event) => event.event === "start")
      .map((event) => event.argv!.slice(1));
    console.log(
      JSON.stringify(
        {
          refsUnchanged: refsAfter === refsBefore,
          metadata: { branchName: null, defaultBranch: "main" },
          defaultBranchReads: getDefaultBranch.mock.calls.length,
          gitCommands: commands,
        },
        null,
        2,
      ),
    );
    expect(commands.some((args) => args.includes("status"))).toBe(true);
    expect(commands.filter((args) => args[0] === "for-each-ref")).toHaveLength(
      0,
    );
    expect(getDefaultBranch).not.toHaveBeenCalled();
  } finally {
    if (previousTrace === undefined) delete process.env.GIT_TRACE2_EVENT;
    else process.env.GIT_TRACE2_EVENT = previousTrace;
    await manager?.shutdown();
    vi.restoreAllMocks();
    await rm(root, { recursive: true, force: true });
  }
});

5. Root cause

Initial watcher processing resolves local state and shared refs together. However, later local-only events do not supply a shared snapshot. reportCurrentBranch treats an absent per-event snapshot as a reason to call getDefaultBranch again, even though the watch already knows the default branch:

sharedRefs === undefined
  ? entry.workspace.getDefaultBranch()
  : sharedRefs.defaultBranch

Workspace.getDefaultBranch delegates to readDefaultBranch. readDefaultBranch and readRepoDefaultBranch validate the repository and resolve origin/HEAD or local fallback refs. Origin HEAD and preferred-local-branch readers explain the measured symbolic-ref and for-each-ref subprocesses. The additional calls occur before metadata deduplication, so unchanged metadata does not prevent them.

Shared-ref snapshots already derive the default branch from refs. Watcher classification distinguishes HEAD/index metadata from shared ref paths (packed-refs, refs/heads, refs/remotes). The test verifies unchanged refs rather than pretending HEAD movement can change the ref-derived default branch.

One wording correction matters: a local event does not necessarily spawn a standalone current-branch query. Local-state snapshots obtain branch metadata from git status. The demonstrated waste is the separate default-branch resolution, not the necessary status read.

6. Proposed fix

Remember the last resolved default-branch value in the existing workspace-watch state and reuse it for local-only events. Refresh it from shared-ref snapshots, retaining a lookup fallback only until a value has been resolved. Keep null (resolved but absent) distinct from undefined (not resolved yet); do not reuse only the displayed fallback, which can be the current branch. Preserve detached-HEAD handling, metadata deduplication, and invalidation when workspace provisioning changes.

Use this regression as the real-Git resource guard, and preserve coverage for shared-ref changes, no-default-branch repositories, and detached HEAD. No production fix was attempted here because an open linked PR already owns the change.
