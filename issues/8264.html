#8264 · Installed launcher replaces a managed CLI connection

BugPriority: MediumEffort: Lowremotecliconfirmed-reproGitHub issue

November 26, 2026 · trusted origin/main b0ddaad731565d7e4de68d824120d802fc78f7d5 · bb-app 0.50.1

REPRODUCED · Root-cause confidence: high

1. TL;DR

The installed npm CLI entry can fail a thread lookup that succeeds through the execution machine’s supplied CLI. Before delegating to that supplied executable, the launcher replaces its inherited loopback proxy URL with the installed server URL and injects configured headers into the environment. The real CLI does not forward those configured headers, so bypassing the real machine-auth proxy removes the authentication header that the proxy normally supplies. Two clean checkouts reproduce direct CLI exit 0 versus launcher exit 1 with HTTP 401. This is an isolated Linux reproduction with the real launcher, bundled CLI, and machine-auth proxy; the native macOS installer and the reporter’s server were not exercised.

5. Root cause

  1. The host’s runtime-shell environment supplies the executable and server URL as a pair: BB_CLI and BB_SERVER_URL.
  2. The installer launcher executes the machine package’s bb entry. It does not itself restore the managed connection.
  3. runBbCli resolves managed runtime configuration before calling the delegation helper: 
    const runtime = await resolveBbAppRuntimeState({
  entrypointUrl: import.meta.url,
  env: process.env,
  homeDir: homedir(),
  options: createDefaultLauncherOptions(),
  serverUrlMode: "managed",
});
  4. Configuration precedence explicitly puts installed config ahead of the inherited URL and merges stored headers into the environment: 
    toOptionalString(args.optionServerUrl) ??
args.config.serverUrl ??
toOptionalString(args.env.BB_SERVER_URL) ??
args.defaultServerUrl
    resolveBbAppRuntimeState applies this policy before the CLI selection is made.
  5. runBundledCliCommand finally selects BB_CLI, sets the recursion marker, and spawns it using the already-mutated environment. Choosing the right executable is too late to preserve the original connection.
  6. The real machine-auth proxy injects target.headers into upstream HTTP requests. The CLI fetch wrapper adds CLI/caller metadata, while the Node transport does not supply environment server headers. Bypassing the proxy therefore sends the request without its machine header and the fixture rejects it.

The environment-header mutation is real, but it is not evidence that those headers reached the network. Fixing only header injection or the recursion marker would not repair the verified URL-precedence failure.

6. Proposed fix and scope decision

Keep the existing standalone installed-configuration policy, but preserve the supplied executable’s connection context when delegating from a managed terminal. Design that as one explicit routing-and-authentication contract rather than globally moving inherited environment variables ahead of installed configuration. Cover absent and present inherited headers, stored machine credentials and explicit stored headers, recursion, and standalone calls.

No automatic PR: safely repairing this behavior changes which routing/authentication context is selected and whether installed machine credential headers apply. That touches authentication configuration precedence, explicitly excluded by this rule’s simple-fix gate. No production fix branch was created, pushed, or opened. No linked open PR was found in issue cross-references or an open-PR search.

import { spawn } from "node:child_process";
import { mkdtemp, rm, writeFile } from "node:fs/promises";
import { createServer, type Server } from "node:http";
import { tmpdir } from "node:os";
import { join, resolve } from "node:path";
import { fileURLToPath } from "node:url";
import { describe, expect, it } from "vitest";
import { resolveBbAppRuntimeState } from "../src/launcher.js";
import {
  startMachineAuthProxy,
  type MachineAuthProxy,
} from "../../../apps/host-daemon/src/machine-auth-proxy.js";

const packageRoot = fileURLToPath(new URL("../", import.meta.url));
const cliPath = resolve(packageRoot, "host-daemon/dist/bb");
const launcherPath = resolve(packageRoot, "dist/bb.js");
const commandArgs = ["thread", "show", "thr_reproduction", "--json"];

interface RequestRecord {
  route: string;
  hasMachineHeader: boolean;
  hasScopedHeader: boolean;
}

async function listen(server: Server): Promise<string> {
  for (let attempt = 0; attempt < 100; attempt += 1) {
    const port = 40000 + Math.floor(Math.random() * 20000);
    try {
      await new Promise<void>((resolveListen, rejectListen) => {
        const onError = (error: Error) => rejectListen(error);
        server.once("error", onError);
        server.listen(port, "127.0.0.1", () => {
          server.off("error", onError);
          resolveListen();
        });
      });
      return "http://127.0.0.1:" + String(port);
    } catch (error) {
      if (
        !(error instanceof Error) ||
        !("code" in error) ||
        error.code !== "EADDRINUSE"
      )
        throw error;
    }
  }
  throw new Error("No isolated fixture port available");
}

async function run(entry: string, env: NodeJS.ProcessEnv) {
  return new Promise<{ code: number | null; stdout: string; stderr: string }>(
    (resolveRun, rejectRun) => {
      const child = spawn(process.execPath, [entry, ...commandArgs], {
        env,
        stdio: ["ignore", "pipe", "pipe"],
      });
      let stdout = "";
      let stderr = "";
      child.stdout.setEncoding("utf8").on("data", (chunk: string) => {
        stdout += chunk;
      });
      child.stderr.setEncoding("utf8").on("data", (chunk: string) => {
        stderr += chunk;
      });
      child.once("error", rejectRun);
      child.once("close", (code) => resolveRun({ code, stdout, stderr }));
    },
  );
}

describe("issue 8264: scoped launcher routing", () => {
  it.each(["machine credential", "explicit server headers"])(
    "preserves the managed connection with %s in stored configuration",
    async (mode) => {
      const root = await mkdtemp(join(tmpdir(), "bb-8264-"));
      const upstreamRequests: RequestRecord[] = [];
      let proxy: MachineAuthProxy | undefined;
      const record = (
        route: string,
        headers: import("node:http").IncomingHttpHeaders,
      ): RequestRecord => ({
        route,
        hasMachineHeader: headers["x-bb-connect-machine"] !== undefined,
        hasScopedHeader: headers["x-test-scoped"] !== undefined,
      });
      const installed = createServer((request, response) => {
        upstreamRequests.push(record(request.url ?? "", request.headers));
        response.setHeader("content-type", "application/json");
        if (
          request.headers["x-bb-connect-machine"] !== "synthetic-machine-value"
        ) {
          response.writeHead(401);
          response.end(
            JSON.stringify({
              error: "Synthetic upstream requires the machine header",
            }),
          );
          return;
        }
        if (request.url === "/api/v1/threads/thr_reproduction") {
          response.end(
            JSON.stringify({ id: "thr_reproduction", environmentId: null }),
          );
        } else if (request.url?.endsWith("/default-execution-options")) {
          response.end("{}");
        } else {
          response.writeHead(404);
          response.end(JSON.stringify({ error: "Fixture route not present" }));
        }
      });
      try {
        const installedUrl = await listen(installed);
        const probe = createServer();
        const proxyPort = Number(new URL(await listen(probe)).port);
        await new Promise<void>((resolveClose) =>
          probe.close(() => resolveClose()),
        );
        proxy = await startMachineAuthProxy({
          port: proxyPort,
          target: () => ({
            url: installedUrl,
            headers: { "x-bb-connect-machine": "synthetic-machine-value" },
          }),
        });
        const scopedUrl = proxy.serverUrl;
        await writeFile(
          join(root, "config.json"),
          JSON.stringify({
            serverUrl: installedUrl,
            ...(mode === "machine credential"
              ? { machineCredential: "synthetic-machine-value" }
              : {
                  serverHeaders: {
                    "x-bb-connect-machine": "synthetic-machine-value",
                  },
                }),
          }),
        );
        const env: NodeJS.ProcessEnv = {
          PATH: process.env.PATH,
          HOME: root,
          BB_DATA_DIR: root,
          BB_CLI: cliPath,
          BB_SERVER_URL: scopedUrl,
          BB_HOST_DAEMON_PORT: "59999",
          BB_THREAD_ID: "thr_reproduction",
          ...(mode === "explicit server headers"
            ? {
                BB_SERVER_HEADERS: JSON.stringify({
                  "x-test-scoped": "synthetic-scoped-value",
                }),
              }
            : {}),
        };
        const direct = await run(cliPath, env);
        const markedDirect = await run(cliPath, { ...env, BB_CLI_REEXEC: "1" });
        expect(direct.code, direct.stderr).toBe(0);
        expect(markedDirect.code, markedDirect.stderr).toBe(0);
        expect(JSON.parse(direct.stdout).thread.id).toBe("thr_reproduction");
        expect(upstreamRequests.length).toBeGreaterThan(0);
        expect(
          upstreamRequests.every((request) => request.hasMachineHeader),
        ).toBe(true);
        const directRequestCount = upstreamRequests.length;
        const runtime = await resolveBbAppRuntimeState({
          entrypointUrl: new URL("../src/bin/bb.ts", import.meta.url).href,
          env,
          homeDir: root,
          options: { help: false },
          serverUrlMode: "managed",
        });
        const wrapped = await run(launcherPath, env);
        console.log(
          JSON.stringify({
            mode,
            upstreamPort: Number(new URL(installedUrl).port),
            proxyPort,
            dataDir: root,
            directExit: direct.code,
            markedDirectExit: markedDirect.code,
            launcherExit: wrapped.code,
            serverUrlPreserved: runtime.env.BB_SERVER_URL === env.BB_SERVER_URL,
            serverHeadersPreserved:
              runtime.env.BB_SERVER_HEADERS === env.BB_SERVER_HEADERS,
            daemonPortPreserved:
              runtime.env.BB_HOST_DAEMON_PORT === env.BB_HOST_DAEMON_PORT,
            directRequestCount,
            launcherRequests: upstreamRequests.slice(directRequestCount),
            launcherError: wrapped.stdout.trim() || wrapped.stderr.trim(),
          }),
        );
        expect(
          wrapped.code,
          "The npm launcher must use the same scoped connection as direct BB_CLI",
        ).toBe(0);
        expect(
          upstreamRequests.every((request) => request.hasMachineHeader),
        ).toBe(true);
      } finally {
        await proxy?.close();
        await new Promise<void>((resolveClose) =>
          installed.close(() => resolveClose()),
        );
        await rm(root, { recursive: true, force: true });
      }
    },
    30000,
  );

  it("uses installed configuration without managed context", async () => {
    const root = await mkdtemp(join(tmpdir(), "bb-8264-standalone-"));
    try {
      await writeFile(
        join(root, "config.json"),
        JSON.stringify({
          serverUrl: "https://installed.example.test",
          machineCredential: "synthetic-machine-value",
        }),
      );
      const runtime = await resolveBbAppRuntimeState({
        entrypointUrl: new URL("../src/bin/bb.ts", import.meta.url).href,
        env: { BB_DATA_DIR: root },
        homeDir: root,
        options: { help: false },
        serverUrlMode: "managed",
      });
      expect(runtime.env.BB_SERVER_URL).toBe("https://installed.example.test");
      expect(JSON.parse(runtime.env.BB_SERVER_HEADERS ?? "{}")).toEqual({
        "x-bb-connect-machine": "synthetic-machine-value",
      });
    } finally {
      await rm(root, { recursive: true, force: true });
    }
  });
