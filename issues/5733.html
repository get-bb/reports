#5733 · Mutable plugin loads rewrite unchanged host artifacts

BugPriority: MediumEffort: Lowplugins · perf · confirmed-reproGitHub issue

October 19, 2026 · trusted origin/main base 9937c46f5c7e369de3563eb864c8cbc4c3b9c231

Verdict: REPRODUCED · Root-cause confidence: high

1. TL;DR

A local plugin's host bundle is compiled again even when its sources and SDK have not changed. The plugin lifecycle loader unconditionally requests a host build for path plugins and source-built builtins. A regression test exercises the real plugin service, builds a temporary fixture, then reloads it or stops and starts the service. Both operations leave the bundle bytes identical but change its modification timestamp. The same two failures occur in a second clean checkout at the same trusted commit.

import {
  mkdir,
  mkdtemp,
  readFile,
  rm,
  stat,
  writeFile,
} from "node:fs/promises";
import { tmpdir } from "node:os";
import { join } from "node:path";
import { afterEach, beforeEach, describe, expect, it } from "vitest";
import { PLUGIN_SDK_VERSION } from "@bb/domain";
import { createMigratedConnection } from "@bb/db/testing";
import { createAiServiceRegistry } from "../../../src/services/ai/ai-service-registry.js";
import {
  createPluginService,
  type PluginService,
} from "../../../src/services/plugins/plugin-service.js";
import { createNoopTelemetryService } from "../../../src/services/system/telemetry.js";
import { testLogger } from "../../helpers/test-app.js";

describe("mutable plugin host build policy", () => {
  let service: PluginService;
  let db: ReturnType<typeof createMigratedConnection>;
  let workDir: string;
  let rootDir: string;
  let artifactPath: string;
  let metaPath: string;

  beforeEach(async () => {
    db = createMigratedConnection();
    workDir = await mkdtemp(join(tmpdir(), "bb-host-build-policy-"));
    service = createPluginService({
      db,
      dataDir: join(workDir, "data"),
      appVersion: "0.9.0",
      bundledPlugins: [],
      aiServices: createAiServiceRegistry(),
      telemetry: createNoopTelemetryService(),
      logger: testLogger,
      hub: {
        getDaemonSessionIdForHost: () => null,
        notifyPluginSignal: () => 0,
        notifySystem: () => {},
      },
    });
    rootDir = join(workDir, "bb-plugin-host-policy");
    artifactPath = join(rootDir, "dist", "host.js");
    metaPath = join(rootDir, "dist", "host.meta.json");
    await mkdir(rootDir, { recursive: true });
    await writeFile(
      join(rootDir, "package.json"),
      JSON.stringify({
        name: "bb-plugin-host-policy",
        version: "0.1.0",
        bb: {
          name: "Host policy fixture",
          description: "Host build lifecycle fixture.",
          branding: { icon: "Zap" },
          server: "./server.ts",
          host: "./host.ts",
        },
      }),
    );
    await writeFile(
      join(rootDir, "server.ts"),
      "export default function plugin() {}",
    );
    await writeFile(
      join(rootDir, "host.ts"),
      'export default { experimental_apiVersion: 1, value: "initial" };',
    );
    const installed = await service.installPath(rootDir);
    expect(installed.status).toBe("running");
  });

  afterEach(async () => {
    await service.stop();
    db.$client.close();
    await rm(workDir, { recursive: true, force: true });
  });

  it.each(["reload", "restart"])(
    "reuses an unchanged host artifact on %s",
    async (operation) => {
      const before = await stat(artifactPath);
      const bytes = await readFile(artifactPath);
      if (operation === "restart") {
        await service.stop();
        await service.start();
      } else {
        expect((await service.reload("host-policy")).ok).toBe(true);
      }
      expect(
        service.list().find((entry) => entry.id === "host-policy")?.status,
      ).toBe("running");
      expect(await readFile(artifactPath)).toEqual(bytes);
      expect((await stat(artifactPath)).mtimeMs).toBe(before.mtimeMs);
    },
  );

  it.each(["source", "artifact", "metadata", "invalid metadata", "SDK"])(
    "rebuilds when the %s changes or disappears",
    async (target) => {
      if (target === "source") {
        await writeFile(
          join(rootDir, "host.ts"),
          'export default { experimental_apiVersion: 1, value: "updated" };',
        );
      } else if (target === "artifact") {
        await rm(artifactPath);
      } else if (target === "metadata") {
        await rm(metaPath);
      } else {
        await writeFile(
          metaPath,
          target === "SDK"
            ? JSON.stringify({ sdkMajor: 0, sdkVersion: "0.0.0-stale" })
            : "not json",
        );
      }

      expect((await service.reload("host-policy")).ok).toBe(true);
      const metadata: unknown = JSON.parse(await readFile(metaPath, "utf8"));
      expect(metadata).toMatchObject({ sdkVersion: PLUGIN_SDK_VERSION });
      const artifact = await readFile(artifactPath, "utf8");
      expect(artifact).toContain(target === "source" ? "updated" : "initial");
    },
  );
});

5. Root cause

The mutable host loader invokes the host builder on every load without checking SDK metadata or source freshness; the builder recompiles and replaces the artifact. The host artifact is still checked for size, metadata validity, and digest after building, but these checks happen too late to avoid compiling it. Frontend loading already has the freshness guard missing here.

  • Host loader and unconditional build, lines 1275–1306.
  • Existing frontend source/directory timestamp walk, lines 1068–1108.
  • Frontend SDK/freshness guard, lines 1220–1258.
  • Host builder directly invokes esbuild, lines 332–370.
if ((kind === "path" || kind === "builtin") && !isPackagedBuiltinEntry(...)) {
  await buildPluginHost(...);
  setDevBuildProblem(row.id, "host", null);
}

The runtime test, rather than a direct builder benchmark, proves the redundant call happens at the actual plugin lifecycle boundary. Static inspection shows the builder has no reuse shortcut. Identical bytes plus changed mtime are therefore an externally observable effect of the needless build, not an assumption based only on code shape.

6. Proposed fix

Reuse the existing mutable-artifact freshness walk with an app/host target. In the mutable host loader, parse existing metadata and build only when it is absent/invalid, its SDK differs, the output is missing, or plugin sources/directories are newer. Keep packaged-builtin eligibility, digest validation, artifact size limits, and explicit build commands unchanged. Preserve the current ignored directories (dist, node_modules, .git) rather than changing dependency or packaging policy.

The focused test intentionally covers both reload and startup, plus five invalidation cases. Existing frontend, prebuilt-server, host artifact serving, and build-problem tests are relevant compatibility checks.
