1. TL;DR

Pi child-launch tool events are translated into ordinary tools rather than delegation items. A newly authored diagnostic sends three successful child operations through the actual Pi translator and shared delta assembler: all three start and finish, but their item kind is toolCall. This result repeated in a second clean trusted checkout. The translator has no child-delegation classification or asynchronous child-completion correlation, while the timeline distinguishes tools from delegations. The third-party extension, macOS desktop display, and completion after the initiating tool returns were not executed, so this is not an end-to-end reproduction of the reported workflow.

5. Root cause

classifyPiToolUse recognizes command and file-change tools, then returns a generic tool for every other name. There is no Pi subagent-specific branch. This classification is retained between tool start and tool end; a successful end closes the same generic shape rather than producing child-delegation identity.

    };
  }

  return { type: "tool", tool: toolName, args };
}

6. Proposed fix and safety gate

Capture a real sanitized extension lifecycle first, including multiple children, launch return, parent turn settlement, child success/failure/cancellation, and late notifications. Validate these external inputs at the Pi boundary. Map each supported child to the existing delegation delta shape with a stable child reference, and use background delegation semantics when the child outlives the initiating tool. Preserve the generic fallback for unknown tools and non-launch management actions.

No automatic production patch or PR: the complete async workflow has not been reproduced under the permitted trusted-code/no-new-dependency constraints. The synthetic test establishes the classification gap but does not establish when a real background child is done. A name-only fix could incorrectly mark launcher completion as child completion. The required faithful pre-fix/post-fix lifecycle regression therefore cannot yet be established; the simple-fix safety gate is not satisfied.
