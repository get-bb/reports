#7223 · Older-history prefetch starts too late for a fast climb

BugPriority: MediumEffort: Mediumthreads · perf · partial-reproGitHub issue

2026-11-07 · trusted base e61446e15a0bb3e6df551e45c3aba5c5187ffad3

Verdict: PARTIALLY REPRODUCED · Root-cause confidence: high for the fixed-threshold timing mechanism, not the reported end-to-end measurements.

1. TL;DR

Older timeline pages are requested only when their sentinel is within 600 pixels of the viewport. A deterministic reproduction exercises the real React hook and its real scroll-position notification owner: it moves the sentinel upward in 100-pixel steps every 25 milliseconds and delays page completion. Both 300 and 900 millisecond page loads remain pending when the loaded edge is reached. A second clean checkout produces identical traces, while the existing 36 related tests pass. This establishes a request-lead-distance limitation; native phone/trackpad flings and the original aggregate wait measurements are not verified.

// @vitest-environment jsdom

import { act, cleanup, renderHook } from "@testing-library/react";
import type { ReactNode } from "react";
import { afterEach, expect, it, vi } from "vitest";
import {
  BottomAnchorContext,
  type BottomAnchorContextValue,
} from "@/components/ui/bottom-anchored-scroll-body.js";
import { ScrollPositionKeeper } from "@/components/ui/scroll-position-keeper.js";
import { useAutoLoadOlderRows } from "./useAutoLoadOlderRows.js";

afterEach(() => {
  cleanup();
  document.body.replaceChildren();
  vi.useRealTimers();
  vi.restoreAllMocks();
});

it.each([300, 900])(
  "has the older page ready at the loaded edge with %i ms page latency",
  async (latencyMs) => {
    vi.useFakeTimers();
    vi.setSystemTime(0);
    const scrollElement = document.createElement("div");
    const sentinel = document.createElement("div");
    document.body.append(scrollElement, sentinel);
    let distancePx = 1_600;
    let requestStartedMs: number | null = null;
    let requestDistancePx: number | null = null;
    let completedMs: number | null = null;
    let pageReady = false;
    vi.spyOn(scrollElement, "getBoundingClientRect").mockImplementation(
      () => new DOMRect(0, 0, 400, 800),
    );
    vi.spyOn(sentinel, "getBoundingClientRect").mockImplementation(
      () => new DOMRect(0, -distancePx - 20, 400, 20),
    );
    const positionKeeper = new ScrollPositionKeeper({
      bottomThresholdPx: 4,
      deferWritesWhileScrolling: false,
      getContentElement: () => null,
      getFloorElement: () => null,
      getFooterElement: () => null,
      getScrollElement: () => scrollElement,
      getTopLevelRows: () => [],
      initiallyAttached: false,
    });
    const anchor: BottomAnchorContextValue = {
      getScrollElement: () => scrollElement,
      isAtBottom: false,
      scrollToBottom: vi.fn(),
      scrollElementIntoView: vi.fn(),
      holdContentPosition: vi.fn(),
      positionKeeper,
    };
    const onLoadOlderRows = vi.fn(() => {
      requestStartedMs = Date.now();
      requestDistancePx = distancePx;
      return new Promise<void>((resolve) => {
        setTimeout(() => {
          pageReady = true;
          completedMs = Date.now();
          resolve();
        }, latencyMs);
      });
    });
    const wrapper = ({ children }: { children: ReactNode }) => (
      <BottomAnchorContext.Provider value={anchor}>
        {children}
      </BottomAnchorContext.Provider>
    );
    const { result } = renderHook(
      () =>
        useAutoLoadOlderRows({
          hasOlderTimelineRows: true,
          isLoadingOlderTimelineRows: false,
          onLoadOlderRows,
        }),
      { wrapper },
    );
    act(() => result.current.sentinelRef(sentinel));

    for (let step = 1; step <= 16; step += 1) {
      await act(async () => vi.advanceTimersByTimeAsync(24));
      distancePx = 1_600 - step * 100;
      act(() => positionKeeper.reconcile());
      await act(async () => vi.advanceTimersByTimeAsync(1));
    }

    const readyAtEdge = pageReady;
    const observedEdgeMs = Date.now();
    await act(async () => vi.advanceTimersByTimeAsync(latencyMs));
    console.log(JSON.stringify({
      latencyMs,
      scrollSpeedPxPerSecond: 4_000,
      requestStartedMs,
      requestDistancePx,
      edgeMs: observedEdgeMs,
      completedMs,
      readyAtEdge,
      pageEventuallyReady: pageReady,
      requestCount: onLoadOlderRows.mock.calls.length,
    }));
    expect(onLoadOlderRows).toHaveBeenCalledTimes(1);
    expect(pageReady).toBe(true);
    expect(readyAtEdge).toBe(true);
  },
);

5. Root cause

The prefetch decision compares the connected sentinel's bottom against the scroll viewport's top minus a constant:

const AUTO_LOAD_OLDER_ROWS_PREFETCH_MARGIN_PX = 600;
sentinelRect.bottom >= scrollRect.top - AUTO_LOAD_OLDER_ROWS_PREFETCH_MARGIN_PX

Position notifications schedule a zero-delay check; no viewport-height, scrolling-speed, or page-latency allowance enters this decision. The test notifies the real position keeper after each step. The first request starts at distance 600 rather than earlier in the 1,600-pixel climb. At an average 4,000 px/s, 600 pixels only buy about 150 ms, less than either simulated request latency.

The in-flight guard remains active until the asynchronous callback completes. The actual timeline sentinel renders a loading status while the older-page flag is true. The timing mechanism explains why the visible loading edge can be encountered before the request finishes, but this report does not claim to have observed that rendering in a real browser.

6. Proposed fix

Increase bounded prefetch lead based on the viewport, or adapt it to measured scroll speed and page latency if necessary. Keep the existing in-flight guard, failure/manual-retry fallback, and scroll anchoring. Validate early-enough completion with asynchronous pages as well as geometry; test large and small viewports, rapid direction changes, failure recovery, request volume, and native touch/wheel input. Any finite distance can still be exhausted by sufficiently fast movement or slow networking, so a larger fixed margin is an improvement, not a guarantee of zero waits.
