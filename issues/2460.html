#2460 · thread.start fails with “Internal error” when omp uses Ox Alpha

BugPriority: HighEffort: Unset ompprovidersprovider-acp open on GitHub 2026-08-27 · base ad79bbb5ec90

Verdict: ALREADY FIXED · Root-cause confidence: high

1. TL;DR

bb 0.39.0 gave omp the provider-bridge bootstrap as a dynamic-tool MCP server.

The bootstrap did not accept the MCP flag, so it stopped before the ACP session opened.

OMP returned bb-bridge: Transport closed, but bb 0.39.0 removed that useful text.

The selected Ox Alpha model did not cause this failure.

Commit aab0cd710d fixed both faults before this report base.

5. Root cause

bb 0.39.0 ran each provider bridge through a general worker program.

The ACP bridge used process.argv[1] as the dynamic-tool MCP program.

That value named the worker, not the ACP bridge module.

The worker received --mcp-stdio, printed its usage text, and stopped.

OMP then rejected ACP session/new because its required bb-bridge transport closed.

The direct run confirms both events. The raw ACP response contains bb-bridge: Transport closed.

The same MCP child command exits with status 1 and prints the bootstrap usage error.

See the raw ACP and bootstrap output.

The faulty code appears in the 0.39.0 bridge.

const entryPoint = process.argv[1]
  ? resolve(process.argv[1])
  : fileURLToPath(import.meta.url);
return [...process.execArgv, entryPoint, "--mcp-stdio"];

The base code uses its module URL. Its comment records the old failure.

See bridge.ts lines 367–373.

// process.argv[1] is the provider-bridge bootstrap, not this module.
return [...process.execArgv, fileURLToPath(import.meta.url), "--mcp-stdio"];

A second fault hid the cause.

The 0.39.0 parser kept only error.message and removed error.data.details.

See the old parser.

The base parser now adds the details. See agent-connection.ts lines 109–120.

const details = formatAgentErrorData(error.data);
return details === undefined ? message : `${message}: ${details}`;

This shared path affected all ACP agents that required the session MCP server.

Ox Alpha only identified the model that the reporter selected.

6. Proposed fix (first principles)

No new code change is necessary.

Commit aab0cd710d implemented the correct fix.

It uses import.meta.url for the MCP child and keeps ACP error details.

Users must update from bb 0.39.0 to bb 0.40.0 or a later release.

Close #2460 as already fixed and as a duplicate of #1918.
