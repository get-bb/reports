#7804 · Empty sidebar metadata changes row geometry

BugPriority: LowEffort: LowuiGitHub issue2026-11-19

Trusted base: d9bcc98cac2b924e4c667e435d721a602e63e4c4 · public repository · REPRODUCED · root-cause confidence: high · reproduction label: confirmed-repro.

1. TL;DR

Enabling sidebar metadata changes row layout even when there is nothing to display. Actual production ThreadRow output and the built application stylesheet reproduce a parent row growing from 28 to 29 pixels on a fine pointer, and a compact row growing from 36 to 40 pixels on a coarse pointer. The preference enables wrapping, padding and automatic row sizing before checking whether any plugin contributes content. An empty, visible outer metadata wrapper also retains a one-pixel top margin after the inner line is hidden. The same agent repeated the browser measurements using a second clean checkout and reproduced every measured value.

5. Root cause

ThreadRow.tsx:459 switches to automatic height plus the standard minimum height whenever the global Metadata preference is true. It does not wait for visible items. On coarse pointers that sets a 40 px minimum even for the compact row whose normal height is 36 px (compact and regular coarse sizing).

ThreadRow.tsx:536 also turns on wrapping, content centering and 4 px top/bottom padding unconditionally. ThreadRow.tsx:680 mounts the outer wrapper as mt-px flex min-w-0 basis-full. The core correctly tracks actual item content with data-has-items (content detection) and hides its empty inner span (empty-line visibility), but hiding the child does not hide its flex wrapper.

Measured on both checkouts: inner marker display:none, wrapper display:flex, wrapper height 0, wrapper margin-top 1 px. A 20 px collapse-control title line plus 8 px vertical padding and that 1 px margin produces 29 px. A plain title line is only 18.5714 px, so its content fits within 28 px, but the empty second line displaces its title. The core empty-content contract works; the owning thread-list layout fails to honor it.

6. Proposed fix

Keep single-line geometry until the row actually contains a metadata element bearing data-has-items. Gate automatic/minimum sizing, wrapping, padding, line-height overrides and the outer metadata wrapper's display together. Preserve compact coarse-pointer sizing when no item is present. Test empty, populated and asynchronously appearing/disappearing items in the browser; do not rely only on comparing class names.
