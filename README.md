# bb reports

HTML reports for [get-bb/bb](https://github.com/get-bb/bb) issues and PRs, published with GitHub Pages at https://get-bb.github.io/reports/.

- `issues/<number>.html` — one report per issue
- `prs/<number>.html` — one report per PR
- put images under `issues/assets/` or `prs/assets/` and link them relatively
- add a link to `index.html` and post the Pages URL as a comment on the issue
